# スカイライン・テクノロジーズ 企業サイト

ソフトウェア開発会社「スカイライン・テクノロジーズ」の企業サイト（1ページ構成）です。
クラウド・AI・業務システムの設計から開発、運用までを手がける会社として、事業内容や実績を紹介します。

## 概要

サイトは `index.html` 1ファイルで完結しています。HTML・CSS・JavaScript をすべて同じファイルに書いているため、ビルドや依存パッケージのインストールは不要です。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと、お問い合わせ・事業内容への導線 |
| 実績数値 | 会社の主な実績を数値で紹介 |
| 事業内容 | クラウドシステム開発、Web・モバイルアプリ、AI・データ活用 など |
| 選ばれる、3つの理由 | 当社の強み |
| 開発の流れ | 相談から運用までのプロセス |
| 導入事例 | 開発実績の紹介 |
| お知らせ | 最新ニュース |
| 会社概要 | 会社情報 |
| お問い合わせ | 問い合わせフォーム |

### 使用技術

- HTML / CSS / JavaScript（外部ライブラリなし）
- Google Fonts（Noto Sans JP、Inter）

## ブラウザで表示する手順

1. このリポジトリをダウンロードまたはクローンします。

   ```bash
   git clone <リポジトリのURL>
   cd company-site
   ```

2. `index.html` をブラウザで開きます。次のどれかの方法で開けます。

   - **エクスプローラーから開く:** `index.html` をダブルクリックします。既定のブラウザで表示されます。
   - **ブラウザにドラッグ＆ドロップする:** `index.html` を開いているブラウザのウィンドウにドラッグします。
   - **コマンドで開く:**

     ```bash
     # Windows
     start index.html

     # macOS
     open index.html

     # Linux
     xdg-open index.html
     ```

> **補足:** フォントは Google Fonts から読み込むため、インターネットに接続していないと別のフォントで表示されます。
